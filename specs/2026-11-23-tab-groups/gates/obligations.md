# Auflagen aus Gate 1: Tab-Gruppen

Auflagen für Bau und QA. Quelle sind die `obligation`-Befunde der Gate-1-Perspektiven `code`, `data` und `ui`; gleiche Auflagen aus mehreren Perspektiven sind zusammengeführt.

| ID | Auflage | Nachweis | Ziel-Schritt | Quelle |
|----|---------|----------|--------------|--------|
| OB-1 | Beschädigte Gruppen-Daten in der gespeicherten Datei (`groups` ist Text, enthält `null` oder Zahlen; `group` ist Text, negativ oder gebrochen) führen nie dazu, dass der ganze Zustand eines Space verworfen wird: alle Tabs laden, die betroffenen lose, ohne Absturz | Lade-Test mit beschädigten Gruppen-Daten | Implementierung | data O-1, code O-3 |
| OB-2 | Umbenennen, Umfärben oder Ein-/Ausklappen allein wird innerhalb der bestehenden Verzögerung geschrieben und sofort bei Fokusverlust, Verstecken und Beenden; ohne Änderung wird nicht geschrieben | Hook-Test mit Zeitgeber; QA: umbenennen, einklappen, beenden, starten | Implementierung, QA | data O-2 |
| OB-3 | Eine Gruppe mit ausschließlich nicht gespeicherten Mitgliedern steht nicht in der Datei, auch ihr Name nicht; die Verweise der folgenden Gruppen bleiben richtig | Hin-und-zurück-Test | Implementierung | data O-3 |
| OB-4 | Die 32-Zeichen-Grenze zählt bei Eingabe und beim Laden gleich; ein Name, den die Eingabe angenommen hat (auch mit Emoji an der Grenze), steht nach dem Neustart unverändert da, nie mit einem halben Zeichen | Lade-Test und Hin-und-zurück mit Emoji-Namen | Implementierung | data O-4, code O-4, ui O-5 |
| OB-5 | Farbwerte 1.5, -1, 8, "2", `null` oder fehlend ergeben die erste Farbe, nie einen undefinierten Farbwert | Lade-Test | Implementierung | data O-5, code O-3 |

Die Auswahl beim Start zählt weiter über alle gespeicherten Tabs des Space, nicht über die sichtbaren | Start- und Hin-und-zurück-Test | Implementierung | data O-6 |

| OB-9 | Wird eine Gruppe eingeklappt und im selben Augenblick ein Tab geschlossen, ist der Nachfolger nie ein Tab der gerade eingeklappten Gruppe; jede Zustands-Aktualisierung sieht den passenden Klappzustand | Test am Tab-Zustand | Implementierung | code O-2 |
| OB-10 | Ist der Vorschau-Tab Mitglied einer Gruppe und wird eine andere Datei als Vorschau geöffnet, steht der neue Tab lose direkt hinter der Gruppe; war die Vorschau das letzte Mitglied, verschwindet die Gruppe | QA in der App | QA | code O-5 |
| OB-11 | Das Namensfeld im Kopf hat nach „Add to new group" und „Rename group" sofort den Fokus und markierten Text, auch in der eingebetteten Web-Ansicht; es liegt nie als Eingabefeld in einem Knopf | Sichtprüfung in der App | Implementierung | ui O-1 |
| OB-12 | Die Markierung des aktiven Tabs sitzt in aufgeklappten Gruppen genau unter dem Tab, auch nach Umsortieren und Klappen | Umsortieren und Klappen in der App | Implementierung | ui O-2 |
